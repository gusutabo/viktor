# Contributing

Thank you for wanting to contribute to Viktor!

## How to contribute

1. Fork this repository
2. Create a branch for your feature: `git checkout -b feature/my-feature`
3. Make your changes and commit: `git commit -m 'Add new feature'`
4. Push to your branch: `git push origin feature/my-feature`
5. Open a Pull Request against the original repository

## Code style

- Keep code simple and readable
- Use clear names for variables and methods
- Separate responsibilities into small classes
- Avoid complex logic in `src/main.rb`

## Project structure

- `src/main.rb` - initialization
- `src/controllers/assistant.rb` - app flow
- `src/views/cli.rb` - user interaction
- `src/services` - persistence and analysis services
- `src/models` - calculation and classification models

## Notes

Please keep the README updated when adding or changing important features.
