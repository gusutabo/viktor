# Contribuição

Obrigado por querer contribuir com o Viktor!

## Como contribuir

1. Fork este repositório
2. Crie uma branch para sua feature: `git checkout -b feature/minha-feature`
3. Faça suas alterações e commit: `git commit -m 'Adiciona nova funcionalidade'`
4. Envie para sua branch: `git push origin feature/minha-feature`
5. Abra um Pull Request no repositório original

## Estilo de código

- Mantenha o código simples e legível
- Use nomes claros para variáveis e métodos
- Separe responsabilidades em classes pequenas
- Evite lógica complexa em `src/main.rb`

## Estrutura do projeto

- `src/main.rb` - inicialização
- `src/controllers/assistant.rb` - fluxo do app
- `src/views/cli.rb` - interação com o usuário
- `src/services` - serviços de persistência e análise
- `src/models` - modelos de cálculo e classificação

## Observações

Por favor, mantenha o README atualizado ao adicionar ou alterar funcionalidades importantes.
